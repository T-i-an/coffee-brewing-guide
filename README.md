# 手冲咖啡指南

一个交互式的手冲咖啡教学网站，帮助咖啡爱好者掌握手冲咖啡的技巧。

## 功能特点

- 详细的步骤指导
- 交互式界面
- 专业的咖啡知识
- 智能咖啡助手
- 响应式设计

## 使用技术

- HTML5
- CSS3
- JavaScript
- DeepSeek AI API

## 在线预览

访问 [手冲咖啡指南](https://你的用户名.github.io/coffee-brewing-guide) 查看在线演示。

## 本地运行

1. 克隆仓库
```bash
git clone https://github.com/你的用户名/coffee-brewing-guide.git
```

2. 打开项目文件夹
```bash
cd coffee-brewing-guide
```

3. 使用浏览器打开 index.html 文件

## 注意事项

- 使用智能助手功能需要配置 DeepSeek API 密钥
- 图片资源需要放在 images 文件夹中
- 建议使用现代浏览器访问以获得最佳体验
